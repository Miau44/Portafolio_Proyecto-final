# Certificate assets

Generated from `respaldos de CV.pdf`.

- Use each certificate's `cover` for the card thumbnail.
- Use `images[].full` inside the click lightbox.
- Certificates with multiple supporting pages can show arrows/dots in the lightbox.
- Keep `object-fit: cover` for cards and `object-fit: contain` in the full-screen viewer.
- Do not crop the full-size image in the lightbox.

See `certifications.json` for the exact mapping.
