# Portafolio de Mauricio Morales 🌿

Portafolio personal de **Mauricio Gonzalo Morales Fernandez**, Ingeniero de Sistemas en La Paz, Bolivia. Presenta experiencia profesional, habilidades técnicas, proyectos, certificaciones y formas de contacto en una página adaptable a móvil y escritorio.

## ✨ Qué encontrarás

- **Perfil y experiencia:** trayectoria profesional, responsabilidades y proyectos realizados.
- **Habilidades:** áreas de especialidad, tecnologías y herramientas.
- **Servicios freelance:** desarrollo de software, automatización, inteligencia artificial y análisis de datos.
- **Certificaciones:** galería con miniaturas y visor para recorrer las páginas disponibles de cada certificado.
- **Proyectos:** tarjetas con filtros por categoría y una vista de detalles.
- **Referencias profesionales:** carrusel para consultar contactos de referencia.
- **Contacto:** formulario que prepara un mensaje en la aplicación de correo del visitante.
- **Idioma:** control ES/EN en el encabezado; la selección se guarda en el navegador.
- **Currículum:** el botón del encabezado abre el CV en Google Drive, desde donde puede consultarse o descargarse.

## 🧰 Tecnologías

El sitio está construido con **HTML5, CSS3 y JavaScript vanilla**. No requiere frameworks, instalación de paquetes ni proceso de compilación. Las animaciones respetan la preferencia de movimiento reducido del dispositivo.

## 📁 Estructura del proyecto

```text
index.html                      Estructura y contenido base de la página
styles.css                      Diseño adaptable, componentes y animaciones
profile.js                      Datos del perfil, experiencia y habilidades
app.js                          Interacciones principales y elementos dinámicos
showcase-data.js                Datos de servicios, certificados, proyectos y referencias
showcase.js                     Filtros, galerías, diálogos, carrusel y formulario
language.js                     Traducciones ES/EN y preferencia de idioma
assets/
├── mauricio-portrait.png        Fotografía de perfil
└── certificates_web/            Miniaturas e imágenes completas de certificados
```

## ▶️ Ejecutar en local

Abre la carpeta con un servidor estático, por ejemplo con la extensión **Live Server** de Visual Studio Code, y visita la dirección local que este genere. El proyecto no necesita `npm install` ni comandos de compilación.

## 🚀 Publicar con GitHub Pages

1. Abre **Settings → Pages** en el repositorio.
2. Selecciona **Deploy from a branch**.
3. Elige la rama `main` y la carpeta `/ (root)`.
4. Guarda los cambios y espera a que GitHub Pages publique el sitio.

## ✍️ Actualizar contenido

- Edita la información profesional, experiencia y habilidades en `profile.js`.
- Actualiza servicios, proyectos, certificaciones y referencias en `showcase-data.js`.
- Añade imágenes de certificados en sus carpetas dentro de `assets/certificates_web/` y conserva la correspondencia de miniaturas y páginas.
- Modifica textos traducidos en `language.js` y contenido estático en `index.html`.
